# 重要的安全注意事项

### 简体中文

###### **其他重要的安全注意事项**

- **射频干扰**

请注意观察禁止或限制使用电子设备的标志和告示。来自此产品的辐射有可能对其他电子设备造成影响，导致它们出现故障。例如：心脏起搏器附近、医疗机构及医疗电子设备附近、飞机机舱内。

- **医疗设备干扰**

此产品包含的磁体以及部分组件会发射电磁场。这些磁体和电磁场可能干扰医疗设备，例如人工耳蜗、助听器、心脏起搏器等其他医疗设备。请使相关医疗设备与此产品保持安全距离。如怀疑产品正在干扰您的医疗设备，请立即停止使用并咨询医师。

- **健康问题**

当不断重复同一动作时（例如打字、玩游戏），您的手、臂、腕、肩、颈或其他身体部位可能会感到不适。如果您感觉到不适，请停止使用此产品，适当休息，如有需要可咨询医师。

- **后果严重的活动**

此产品不适合用于可能因设备故障而导致死亡、人身伤害或重大环境破坏的活动。

- **窒息危险**

此产品含有细小部件，某些部件可能会造成孩童窒息或其它伤害。请将此产品放在孩童接触不到的地方。

- **液体入侵**&#x20;

此产品是一种内含大量电路和电容的电子产品，请注意防止水或其它液体的浸入，因为这可能会导致产品损坏或其他安全问题。

- **拆解产品**

对此产品进行任何未经授权的维修、改装、拆解或撕毁产品标贴都将使产品失去保修。

- **静电电击**

在空气比较干燥的区域使用（金属外壳版本）此产品时，容易聚集静电，您接触产品外壳时可能会遭受产品的静电放电。请避免在极其干燥的环境中使用此产品。或者在使用此产品前触摸已接地的未上漆的金属物体。

- **设备的废弃处理**

不得将具有此符号的设备混入生活垃圾一同废弃处理。根据法律规定，在您的经销商处或市政收集点废弃处理该设备。

- **内置电池安全（此处仅适用于含电池版本的产品）**

产品内置不可拆卸电池。请勿自行拆卸、更换或刺穿电池。任何不当操作可能导致电池损坏、过热、泄漏、起火或爆炸，并存在安全风险。

请仅使用产品随附的原装数据线，并通过电脑的 USB 端口为设备充电。使用非原装线缆、第三方充电器或不符合规格的电源，可能导致充电异常、电池性能下降或产生安全隐患。

请在通风良好、环境温度适宜的条件下为产品充电。避免将产品放置在床、沙发等柔软表面，或置于密闭容器中，以防过热。

避免将产品长时间暴露于极端温度环境中（包括但不限于暴晒的车辆内部、靠近火源的区域或极端寒冷的户外环境），否则可能影响电池性能、缩短使用寿命，甚至引发安全问题。

产品废弃时，请勿作为生活垃圾处理。请遵循当地法律法规的要求，将产品交由指定的电子废弃物回收机构处理。

請遵守所有禁止或限制使用電子設備的標誌及告示。本產品所產生的射頻能量可能會干擾附近的電子設備，導致其發生故障。例如：心律調節器（心臟起搏器）附近、醫療機構、醫療電子設備附近及飛機機艙內。

- 健康問題

長時間重複進行相同動作（例如打字或玩遊戲）時，您的手部、手臂、手腕、肩膀、頸部或身體其他部位可能會感到不適。如感到不適，請停止使用本產品並適當休息；如有需要，請諮詢醫師。

- 高風險活動

本產品不適用於因設備故障可能導致死亡、人身傷害或重大環境損害的用途。

窒息危險

本產品含有細小零件，可能導致兒童窒息或造成其他傷害。請將本產品放置於兒童無法接觸的地方。

液體接觸

本產品為內含電子電路及電子元件的電子產品。請避免本產品接觸水或其他液體，以免造成產品損壞或引發安全風險。

拆解產品

未經授權維修、改裝、拆解本產品，或移除、毀損產品標籤，均會導致保固失效。

靜電放電

在空氣較乾燥的環境中使用本產品（金屬外殼版本）時，產品表面可能累積靜電。接觸產品外殼時，可能會發生靜電放電。請避免在極度乾燥的環境中使用本產品，或於使用前先觸摸已接地且未上漆的金屬物體，以降低靜電發生的機率。

標有此符號的產品不得與一般家庭垃圾一同丟棄。請依照當地法規，透過經銷商或指定的電子廢棄物回收點進行回收處理。

內建電池安全（僅適用於內建電池版本）

本產品內建不可拆卸式電池。請勿自行拆卸、更換或刺穿電池。任何不當操作均可能導致電池損壞、過熱、洩漏、起火或爆炸，並造成安全風險。

請僅使用產品隨附的原廠 USB 線材，並透過電腦的 USB 連接埠為本產品充電。使用非原廠線材、第三方充電器或不符合規格的電源，可能導致充電異常、電池性能下降或產生安全風險。

請於通風良好且環境溫度適宜的條件下為本產品充電。避免將本產品放置於床鋪、沙發等柔軟表面，或密閉空間內充電，以免過熱。

避免長時間將本產品暴露於極端溫度環境中（包括但不限於長時間停放於烈日曝曬的車內、靠近火源或極低溫的戶外環境），否則可能影響電池性能、縮短使用壽命，甚至引發安全問題。

本產品報廢時，請勿與一般家庭垃圾一同丟棄。請依照當地法律法規，交由指定的電子廢棄物回收機構進行回收處理。



### 日本語

###### 重要な安全上の注意

- 電波干渉

電子機器の使用が禁止または制限されている場所では、すべての表示や案内に従ってください。本製品が発する電波は、周囲の電子機器に干渉し、誤作動を引き起こすおそれがあります。特に、心臓ペースメーカーの近く、医療機関や医療機器の近く、航空機内では十分ご注意ください。

- 医療機器への影響

本製品には磁石および電磁場を発生する部品が含まれています。これらは心臓ペースメーカー、人工内耳、補聴器などの医療機器の動作に影響を及ぼすおそれがあります。本製品と医療機器の間は十分な距離を保ってください。本製品が医療機器に影響を及ぼしていると思われる場合は、直ちに使用を中止し、医師にご相談ください。

- 健康に関する注意

タイピングやゲームなどの繰り返し動作を長時間続けると、手、腕、手首、肩、首などの部位に痛みや不快感を生じることがあります。不快感を覚えた場合は使用を中止し、十分に休憩してください。症状が続く場合は、医師にご相談ください。

- 高リスク用途

本製品は、故障した場合に死亡、重大な人身事故または深刻な環境被害につながるおそれのある用途で使用することを目的としていません。

- 窒息の危険

本製品には小さな部品が含まれています。特にお子様が誤飲すると、窒息やけがの原因となるおそれがあります。お子様の手の届かない場所に保管してください。

- 液体との接触

本製品は精密な電子回路を内蔵しています。水やその他の液体が本製品に付着したり、内部に入り込んだりしないようにしてください。故障や安全上の問題の原因となるおそれがあります。

- 製品の分解

本製品を無断で修理、改造または分解したり、製品ラベルを剥がしたり破損したりした場合は、保証の対象外となります。

- 静電気放電（ESD）

乾燥した環境で本製品（金属筐体モデル）を使用すると、静電気が蓄積されることがあります。製品の表面に触れた際に静電気放電（ESD）が発生する場合があります。静電気放電のリスクを軽減するため、極端に乾燥した環境での使用は避け、使用前にアースされた塗装されていない金属に触れてください。

- 製品の廃棄

このマークが表示されている製品は、家庭ごみとして廃棄しないでください。お住まいの地域の法令に従い、販売店または指定の電気・電子機器回収施設で適切に廃棄してください。

- 内蔵バッテリーに関する安全上の注意（内蔵バッテリー搭載モデルのみ）

本製品には取り外しできない内蔵充電式バッテリーが搭載されています。バッテリーを分解、交換、または穴を開けないでください。不適切な取り扱いは、バッテリーの損傷、過熱、液漏れ、発火、爆発などを引き起こし、安全上の危険につながるおそれがあります。

充電には付属のUSBケーブルのみを使用し、パソコンのUSBポートから充電してください。&#x20;

純正以外のケーブル、第三者製の充電器、または仕様に適合しない電源を使用すると、充電異常、バッテリー性能の低下、安全上の問題が発生するおそれがあります。

充電は風通しが良く、適切な周囲温度の環境で行ってください。ベッドやソファなどの柔らかい場所や、密閉された場所での充電は避け、過熱を防いでください。

本製品を極端な高温または低温環境（炎天下の車内、熱源の近く、極寒環境など）に長時間放置しないでください。バッテリー性能の低下や寿命の短縮、安全上の問題の原因となるおそれがあります。

製品を廃棄する際は、家庭ごみとして処分しないでください。お住まいの地域の法令に従い、指定の電気・電子機器回収施設で適切に廃棄してください。
